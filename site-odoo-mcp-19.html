02 — PREMISE

It reads the schema first, then queries.

Standard MCP servers guess field names, wasting API calls and triggering security errors. We fetch metadata before the first byte of data moves.

# Step 1: Resource Discovery
read_resource("odoo://model/sale.order/quick-schema")

# Step 2: Validated Execution
execute_method("sale.order", "search_read", 
  kwargs_json='{"domain": [["state","=","sale"]], "fields": ["name","amount_total"], "limit": 10}')

03 — THE_SAFETY_LAYER

CLASSIFICATION_MATRIX

LEVEL PROTOCOL
SAFE Execute immediately. Read-only operations and non-destructive methods.
MEDIUM Confirm in strict mode. Operations with potential minor side-effects.
HIGH ALWAYS confirm. Financial records, inventory moves, status transitions.
BLOCKED Security-critical models. Always refuse outright.

GATED_CALL_RESPONSE

{ "pending_confirmation": true, "reason": "HIGH_RISK_OP", "requires": "confirmation_token" }

CONFIRMATION_EXCHANGE

ymzyOtsZTDTJpKKysu_xWQ

* Single-use, 120s TTL, bound to (model, method, payload_digest). Confirmed=true alone DOES NOT bypass this gate.
